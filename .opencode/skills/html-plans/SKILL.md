# HTML plans

For a new page or a large markup change, show a short plan and wait for my OK.
Small edits (an attribute, a class, a text change) need no plan.

## Plan

- Goal: what the page must do.
- Structure: a short tree of semantic elements (header, nav, main, section, footer).
- Accessibility: heading order, labels, alt text, focus order.
- Styling: follow the project's existing CSS conventions, no new framework.
- Edge cases: empty states, long text, mobile width.

Bullets only. After approval, build exactly that; if scope changes, re-plan.
